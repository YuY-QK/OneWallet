# 《OneWallet》原型说明

> 版本 v1.0 · 2026-11-10 · 状态：待确认。页面编号沿用 PRD。
> 本文是文字版线框。可点击的 HTML 原型在视觉方向确定后制作（见第 2 节）。

## 1. 信息架构

```
底部导航（4 个 Tab）
├─ 总览    P02
├─ 账户    P03（顶部分段：账户｜地址簿 P10）
├─ 保险库  P12（顶部卡片进入备份清单 P11）
└─ 设置    P18
全局入口：右上角 "+"（P04）出现在总览和账户页
全局遮罩：解锁页 P00 覆盖在任何页面之上
```

**多端布局**：本文线框均为窄屏（手机）。中屏和宽屏的规则见 PRD 7.3：导航从底部 Tab 变为左侧栏；P03 与 P07/P08、P12 与 P15、P10 与地址面板这几组"列表加详情"在宽屏下并排显示；P02 在宽屏下左侧放总资产与曲线、右侧放分布列表。页面内容本身不变。

## 2. 视觉方向（三选一，待你选择）

| 方向 | 一句话 | 关键词 |
|---|---|---|
| A 沉稳金融（建议） | 像银行 app 一样克制，让人放心 | 深蓝灰主色、白底卡片、细线分隔、等宽数字、少量绿色与红色表示涨跌 |
| B 极简黑白 | 几乎没有颜色，数据就是界面 | 纯黑白、超大数字、无卡片、靠留白分组，状态色只用于备份清单 |
| C 柔和现代 | 亲和、圆润，降低"管钱"的紧张感 | 大圆角、浅色渐变卡片、柔和紫蓝主色、圆形图标 |

三种方向都同时提供浅色和深色。建议 A：这个 app 的核心是信任感，备份清单的红、橙、绿在克制的底色上最醒目。

## 3. 通用规范

**布局**：左右边距 16；卡片间距 12；列表行高不小于 56；可点击区域不小于 44×44。

**数字**：金额和数量使用等宽数字；估值保留 2 位小数；地址缩略为前 6 位加后 4 位（`0x1234…abcd`）。

**状态色**：绿表示已完成或上涨；红表示未备份、失败或下跌；橙表示需注意。颜色之外必须同时有图标或文字，不单靠颜色区分。

**通用弹层**
- 底部操作面板：用于地址操作、备份状态操作、长按菜单。
- 确认对话框：危险操作使用，确认按钮为红色并写明动作（如"删除账户"），不使用笼统的"确定"。
- 轻提示：操作结果反馈，2 秒后消失。
- 保险库验证弹层：先调起系统生物识别；失败或不可用时切换为主密码输入。

**通用页面状态**
- 空：插图、一句说明、一个主按钮。
- 加载：骨架屏；有缓存时用顶部细进度条代替。
- 错误：说明原因（用人能看懂的话）、"重试"按钮。
- 离线：顶部横幅"当前离线，数据截至 MM-DD HH:mm"。

**敏感页面**（P14、P15、P16 派生过程、P17 密码步骤）：顶部显示锁形标记；禁止截屏；切后台即遮挡。

## 5. 关键流程图

**首次使用**
```
P01 欢迎 → 安全须知 → 设 PIN → 生物识别 → P02（空）→ P04 → P05/P06 → P02（有数据）
```

**助记词入库**
```
P11「去入库」→（未启用则 P13）→ P14 输入 → 验证 → 保存 → P16 勾选地址 → 加入观察
→ 回到 P11（该钱包变绿）
```

**紧急取回**
```
P00 解锁 → 保险库 Tab → P15 → 验证 → 抄录助记词
```

**换机**
```
旧机：P17 导出 → 存到电脑或 U 盘
新机：P01「从备份恢复」→ 选文件 → 备份密码 → 预览 → 设 PIN → 设主密码 → P02
```
