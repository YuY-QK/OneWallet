# 《OneWallet》界面设计规范

> 版本 v1.0 · 2026-11-10 · 视觉方向 A「沉稳金融」
> 参考实现：`docs/prototype.html`。本文的取值与原型一致；两者不一致时以本文为准并修正原型。

## 1. 原则

- 克制：颜色只用于表达状态和可操作性，不做装饰。
- 数据优先：金额、数量、地址是界面的主角，使用等宽数字。
- 状态不只靠颜色：红、橙、绿必须同时配文字或图标。
- 浅色与深色同等对待。

## 2. 颜色

所有颜色通过主题令牌使用，代码中不写死色值。

| 令牌 | 用途 | 浅色 | 深色 |
|---|---|---|---|
| `bg` | 页面背景 | `#F1F3F7` | `#0E141C` |
| `surface` | 卡片、列表、输入框背景 | `#FFFFFF` | `#17202B` |
| `ink` | 主要文字 | `#16202E` | `#E6ECF3` |
| `muted` | 次要文字、说明 | `#5E6B7D` | `#93A1B3` |
| `line` | 分隔线、边框 | `#DCE2EA` | `#263241` |
| `brand` | 主按钮、选中态、链接、图表线 | `#1F3A5F` | `#8DB4E2` |
| `brandInk` | 主按钮上的文字 | `#FFFFFF` | `#0E141C` |
| `brandSoft` | 选中底色、悬停底色、图表填充 | `#E6ECF4` | `#1D2A3A` |
| `up` / `upSoft` | 上涨、成功、已备份 | `#1B7F52` / `#E2F2EA` | `#4CC38A` / `#173326` |
| `down` / `downSoft` | 下跌、失败、未备份、危险操作 | `#C2362B` / `#FBE7E4` | `#F0766B` / `#3A1D1A` |
| `warn` / `warnSoft` | 需注意、无助记词钱包 | `#A8690F` / `#FAEFD9` | `#E0A84A` / `#382B12` |

## 3. 字体

| 角色 | 字体 | 说明 |
|---|---|---|
| 正文与标题 | 系统中文字体（iOS 苹方、Android 思源黑体），西文 IBM Plex Sans | 随 app 打包 Plex Sans |
| 数字、地址、助记词 | IBM Plex Mono | 等宽数字，随 app 打包 |

| 级别 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| 大数字 | 28 / 34 | 600 | 总资产 |
| 页面标题 | 17 / 24 | 600 | 顶栏 |
| 强调 | 16 / 24 | 600 | 卡片标题 |
| 正文 | 14 / 21 | 400；行标题 500 | 列表、表单 |
| 说明 | 12.5 / 18 | 400 | 次要信息 |
| 标签 | 11.5 / 16 | 500 | 状态胶囊 |

字号随系统"字体大小"设置缩放，布局不得因放大到 130% 而截断关键数字。

## 4. 间距与形状

- 间距刻度：4、6、8、12、16、20、28。页面左右边距 16；区块间距 12。
- 圆角：卡片与列表 10；输入框与分段控件 8；小按钮 7；状态胶囊全圆。
- 边框：1 像素 `line`。不使用阴影。
- 列表行最小高度 54；可点击区域不小于 44×44。

## 5. 组件

| 组件 | 规格 |
|---|---|
| 顶栏 | 返回键、标题、右侧至多两个图标按钮；敏感页面显示"敏感页面"标记 |
| 底部导航（窄屏） | 四项；选中项用 `brand` 文字加顶部 2 像素指示线 |
| 侧边导航（中屏、宽屏） | 同样四项；中屏只显示图标，宽屏显示图标与文字 |
| 卡片 | `surface` 背景、边框、内边距 14；只用于摘要和需要突出的内容 |
| 列表 | 一个圆角容器内的若干行，行间用分隔线；行结构：头像、标题与副标题、右侧值 |
| 头像 | 圆形表示币种与钱包；圆角方形表示交易所与保险库条目 |
| 主按钮 | `brand` 背景，整行宽，高 44 以上；每个页面至多一个 |
| 次按钮 | 透明背景加边框 |
| 危险按钮 | `down` 文字加边框；文案写明动作 |
| 分段控件 | `brandSoft` 底，选中项为 `surface` |
| 状态胶囊 | 对应的浅色底加深色字：绿（已入库、成功）、红（未备份、失败）、橙（需注意） |
| 提醒条 | 整行可点击，橙色或红色浅底，右侧箭头 |
| 占比条 | 4 像素高，`brand` 填充 |
| 助记词网格 | 三列，每格带序号，等宽字体 |
| 遮挡块 | 斜纹底加虚线边框，中间放"验证后查看"按钮 |
| 图表 | 线为 `brand` 1.8 像素，下方 `brandSoft` 填充；只标最高与最低两条刻度线；末端实心圆点 |

## 6. 文案

- 按钮写动作：`保存`、`测试并保存`、`导出加密备份`、`删除账户`。不用笼统的"确定"。
- 错误信息说明发生了什么和能做什么：`API Key 已失效，请更换`。
- 金额隐藏时显示 `****`。
- 地址缩略为前 6 位加后 4 位。
- 术语统一遵循 PRD 第 1 节的名词表。

## 7. 响应式

断点与导航规则见 PRD 7.3。内容区在宽屏下最大宽度 1200，列表详情并排时列表栏宽 320–380。
