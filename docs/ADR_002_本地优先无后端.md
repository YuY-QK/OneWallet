# ADR 002：本地优先，不设自有后端

状态：已确认 · 2026-11-10

## 背景

应用需要查询链上余额、交易所余额和价格。可以由自有服务器代为聚合，也可以由 app 直接请求各数据服务。

## 选项

| 选项 | 优点 | 缺点 |
|---|---|---|
| A. 无后端，app 直连第三方服务 | 密钥与数据不经过任何自有服务器；没有服务器成本和运维；没有"服务器被攻破"的风险 | 用户需自备数据服务的 API Key；受免费额度与限频约束；地址与 IP 暴露给数据服务商；无法做后台推送 |
| B. 自建聚合后端 | 用户免配置；可缓存、可推送；可隐藏第三方 Key | 服务器知道用户全部地址；需要运维和费用；成为攻击目标；交易所 Key 若经服务器则风险极高 |

## 决定

选 A。

- 所有请求由 app 直接发往数据服务商和交易所。
- 用户在 P20 自行配置数据服务的 Key。
- 多设备之间通过加密备份文件迁移数据。

## 后果

- v1.0 没有推送提醒、没有后台同步、没有多设备自动同步。
- 数据访问层全部面向接口（`ChainAdapter`、`PriceSource`）。将来若对外发布并需要免配置体验，可新增一个"经由自有代理"的实现，只代理公开的链上数据与价格查询。
- 无论将来是否有后端，以下两点不变：交易所凭据只在设备上使用，不经过任何服务器；保险库永不联网。
