### 名词统一

| 名词 | 含义 |
|---|---|
| 账户 | 一个资产来源。分两类：钱包账户、交易所账户 |
| 钱包账户 | 一个链上钱包，包含一条或多条链上的若干地址。例："Uni 钱包" |
| 交易所账户 | 通过只读 API Key 接入的一个交易所账户。例："Binance 主账户" |
| 地址 | 某条链上的一个公开地址，属于某个钱包账户 |
| 观察 | 只凭公开地址查询余额，不持有密钥 |
| 密钥条目 | 保险库中的一条记录：一组助记词或一个私钥 |
| 保险库 | 存放密钥条目的加密存储，独立于看板数据 |
| 应用锁 | 进入 app 时的解锁（PIN 或生物识别） |
| 主密码 | 保险库的密码，用于换机恢复和生物识别失效时的兜底 |
| 备份清单 | 每个钱包账户的备份状态汇总 |
| 加密备份文件 | 导出的 `.owbak` 文件，只靠备份密码即可解密 |
| 计价货币 | 资产估值所用货币，默认 USD，可切换 CNY |

## 2. 产品定位

**一句话**：本地优先的个人加密资产看板加离线密钥保险库。

**核心价值**

1. 一处看全：链上钱包和交易所资产汇总。
2. 备份不丢：清楚知道每个钱包是否有备份，并有一个安全的地方存放。
3. 不依赖任何人：没有自有服务器；备份格式公开，app 本身消失也能解密。

**产品原则**

- **只看不动**：app 不产生任何链上交易，不调用交易所的交易或提现接口。
- **密钥不出设备**：助记词、私钥、API Secret 只存在本机，不上传任何地方。
- **保险库不联网**：保险库相关代码没有网络能力。
- **宁可少显示，不可错显示**：数据不确定时标注"未同步"或"估值缺失"，不显示可能错误的数字。
- **危险操作必须明示**：查看助记词、导出备份、删除密钥前，都要明确告知后果。
- **为多端而设计**：v1.0 只发布手机端，但页面按"窄屏、中屏、宽屏"三档布局定义，业务规则不依赖手机特有能力；平台能力不足时功能降级而不是缺失（见 7.3）。

## 3. 目标与成功标准

| 目标 | 判断标准 |
|---|---|
| 资产看全 | 作者名下全部钱包和四家交易所都已接入；app 显示的各交易所总额与官方 app 相差在 1% 以内 |
| 备份齐全 | 备份清单上所有钱包账户状态为"已入库"或"已标记离线备份" |
| 可恢复 | 在另一台手机上用加密备份文件加备份密码完整恢复；用独立解密工具在电脑上解出助记词 |
| 派生正确 | 保险库派生出的地址与原钱包 app 显示的地址逐一相同 |
| 日常可用 | 冷启动到看到上次缓存的总资产不超过 2 秒；一次全量同步不超过 30 秒（20 个地址加 4 个交易所） |

## 5. 产品范围

### 包含（v1.0）

- 应用锁与首次引导
- 钱包账户的观察地址管理：EVM 系六条链、Bitcoin、Solana、Tron
- 交易所账户只读接入：Binance、OKX、Bybit、Bitget
- 总览、账户列表、账户详情、单币种详情
- 地址簿
- 净值曲线（基于本地每日快照）
- 备份清单
- 保险库：助记词和私钥的导入、查看、派生地址
- 加密备份导出与恢复
- 设置：安全、数据源、计价货币、同步状态

### 明确不包含

- 签名、转账、交易、DApp 连接、WalletConnect
- 在 app 内生成新助记词（避免成为资产的原始来源；v1.0 只做已有密钥的保管）
- 后端、账号、云同步、推送通知
- 会员、付费、广告
- 交易流水、盈亏、报税
- DeFi 仓位（LP、借贷、质押）解析、NFT

### 后续候选

- 交易流水与内部划转识别
- 盈亏分析、CSV 导出
- 价格和余额变动的本地提醒
- DeFi 仓位（接第三方聚合 API）
- 更多链和交易所
- 英文界面
- 桌面端（macOS、Windows、Linux）与平板适配
- 设备间端到端加密同步（不经自有服务器，如局域网或用户自己的网盘）

## 6. 核心规则与核心循环

### 6.1 账户与地址

- R1 钱包账户至少有一个地址；交易所账户没有地址，但可缓存其充值地址（只读展示）。
- R2 同一条链上的同一个地址在全 app 内唯一，不能重复添加；重复时提示它已属于哪个账户。
- R3 EVM 地址在六条 EVM 链上通用：添加一个 EVM 地址时，默认勾选全部六条链，可取消。
- R4 地址校验：EVM 校验格式与 EIP-55 校验和（全小写也接受）；Bitcoin 支持 `1`、`3`、`bc1q`、`bc1p` 开头的格式并校验；Solana 校验 Base58 与长度；Tron 校验 `T` 开头的 Base58Check。
- R5 账户可设置名称、图标颜色、备注、来源钱包（Uni、MetaMask、OKX Web3、Bitget Wallet、其他）。
- R6 删除账户会删除其地址、余额缓存和历史快照中的该账户明细；不会删除保险库里关联的密钥条目，但会解除关联。

### 6.2 资产与估值

- R7 余额按"账户 → 位置 → 币种"记录。位置：链上为链名；交易所为现货、资金、合约、理财等子账户。
- R8 币种归一化：不同链、不同交易所的同一种币合并为一个标准币种（如各链 USDT 合并为 USDT）。无法识别的代币以"链 + 合约地址"独立显示，不参与合并。
- R9 估值 = 数量 × 标准币种价格。没有价格的币种估值记为"—"，不计入总资产，并在总览显示"N 个币种无估值"。
- R10 垃圾代币过滤：链上代币默认只显示在价格源中有价格的；其余归入"未识别代币"折叠区，可手动设为显示或隐藏。
- R11 小额隐藏：默认隐藏估值低于 1 USD 的币种，可在设置中关闭。
- R12 交易所合约账户以账户权益计入，不展开持仓明细。

### 6.3 同步

- R13 触发时机：解锁进入 app 时（距上次同步超过 5 分钟）、在总览或账户页下拉刷新、添加账户后立即同步该账户。
- R14 不做后台定时同步（v1.0）。
- R15 每个数据源独立同步，互不阻塞；任一失败不影响其他，失败的账户保留上次数据并标记"同步失败 + 上次成功时间"。
- R16 每天第一次全量同步成功后写入一条净值快照；当天之后的同步覆盖当天快照。有账户同步失败时，该账户沿用上次余额计入快照，并在快照上记录"不完整"。
- R17 遇到限频时自动退避重试，最多 3 次。

### 6.4 应用锁

- R18 首次启动必须设置 6 位数字 PIN，可选开启生物识别。
- R19 app 进入后台超过设定时间（默认立即，可选 1 分钟、5 分钟）后再回来需重新解锁。
- R20 PIN 连续输错 5 次后锁定 1 分钟，之后每多错一次锁定时间翻倍，上限 1 小时。
- R21 app 切到后台时，系统任务切换器中的预览画面被遮挡。

### 6.5 保险库

- R22 保险库首次使用时必须设置主密码：至少 10 个字符，并显示强度提示。主密码无法找回，页面必须明确告知并要求用户勾选确认。
- R23 保险库有独立的锁定状态。进入保险库 Tab 可看到条目名称和类型，不需要额外验证；查看任何密钥明文都需要生物识别或主密码。
- R24 每次查看明文都要单独验证，不存在"保险库已解锁一段时间"的状态。
- R25 明文显示页：默认遮挡，按住或点击后显示；显示 60 秒后自动遮挡；离开页面立即清除。不提供复制到剪贴板（见未决问题 Q3）。
- R26 明文显示页禁止截屏和录屏（Android 用系统标志实现；iOS 检测到录屏或投屏时隐藏内容，截屏后给出警示）。
- R27 导入助记词时校验 BIP39 词表与校验和，支持 12、15、18、21、24 个词，支持可选的 BIP39 passphrase（"第 25 个词"）。校验失败不允许保存。
- R28 导入私钥时须选择链类型，校验格式后保存。
- R29 导入成功后进入派生地址页（P16），用户选择要加入观察的地址；也可跳过。
- R30 生物识别信息变更（新增指纹或面容）后，硬件密钥失效，下次查看须输入主密码，验证后重新启用生物识别。
- R31 主密码连续输错 5 次后锁定，规则同 R20。
- R32 删除密钥条目需要输入主密码，并二次确认"我已另有备份"。
- R33 保险库中的任何内容不写入日志、不进入崩溃报告、不随系统云备份。

### 6.6 备份清单

- R34 每个钱包账户有一个备份状态，取以下之一：

| 状态 | 条件 | 颜色 |
|---|---|---|
| 已入库 | 已关联保险库中的密钥条目 | 绿 |
| 已离线备份 | 用户自行标记"我有纸质或其他离线备份" | 绿 |
| 无助记词钱包 | 用户标记该钱包为 MPC 或社交登录型，无法导出 | 橙 |
| 未备份 | 以上皆非 | 红 |

- R35 "已入库"与"已离线备份"可同时成立，清单中两个标记都显示。推荐状态是两者皆有。
- R36 离线备份可记录"上次核对日期"；超过 180 天未核对时显示提醒。
- R37 交易所账户不出现在备份清单主体中，在清单底部以固定说明呈现："交易所资产没有私钥可备份，请启用二次验证并保管好账号凭据。"
- R38 加密备份文件的"上次导出时间"显示在清单顶部；保险库内容在上次导出之后有变化时，提示"有未备份的更改"。

### 6.7 加密备份

- R39 备份内容：全部账户、地址、标签、备份清单状态、保险库全部密钥条目、设置。可选是否包含交易所 API Key（默认不包含）。不包含余额缓存和快照（见未决问题 Q5）。
- R40 导出时须设置备份密码，默认建议与主密码相同，也可单独设置。
- R41 导出通过系统分享面板保存文件，app 不指定云端位置。导出后提示："请把文件存到手机以外的地方"。
- R42 恢复有两种入口：首次引导页的"从备份恢复"；设置内的"导入备份"（合并到现有数据，冲突时以用户选择为准）。
- R43 备份文件格式公开，仓库提供独立的离线解密工具。

### 6.8 核心循环

解锁 → 同步 → 总览 →（查看分布｜处理备份清单红点｜添加账户）→ 退出。

## 8. 各页面需求

每页按"目的、元素、操作规则、页面状态"描述。

### P00 解锁

**目的**：验证使用者身份。

**元素**：应用图标；PIN 输入点位（6 位）；数字键盘；生物识别按钮（已开启时）。

**操作规则**
- 进入页面时，若已开启生物识别，自动弹出系统验证。
- 生物识别失败或取消后停留在 PIN 输入。
- PIN 输满 6 位自动校验；正确则进入主框架，错误则抖动并清空。
- 错误次数与锁定规则见 R20；锁定期间键盘禁用并显示倒计时。

**页面状态**：正常；输入错误；锁定倒计时。

### P01 首次引导

**目的**：建立安全预期，完成应用锁设置。

**步骤**
1. **欢迎**：一句话介绍；两个按钮："开始使用"、"从备份恢复"（跳 P17 恢复流程）。
2. **安全须知**：三条要点（只读不转账；密钥只存本机；主密码和 PIN 无法找回）。须点"我已了解"才能继续。
3. **设置 PIN**：输入两次，不一致则重来。
4. **生物识别**：设备支持时询问是否开启，可跳过。
5. **完成**：进入总览空状态。

**操作规则**：步骤不可跳过（第 4 步除外）；中途退出后下次启动从第 1 步重来。

### P02 总览

**目的**：一眼看到总资产和分布。

**元素（自上而下）**
1. 顶栏：标题；隐藏金额开关（眼睛图标）；"+" 添加账户。
2. 总资产卡片：总估值、计价货币、24 小时变化（金额和百分比）、上次同步时间。
3. 净值曲线：区间切换 7 天、30 天、90 天、全部。
4. 提醒卡片（按条件出现）：
   - 备份清单有"未备份"或"无助记词钱包"时："N 个钱包尚未备份" → P11。
   - 有账户同步失败时："N 个账户同步失败" → P21。
   - 有未备份的更改时："保险库有更改尚未导出备份" → P17。
5. 分布切换：按币种｜按账户｜按类型（链上与交易所）。
6. 分布列表：每行显示图标、名称、数量（按币种时）、估值、占比条。
7. 列表底部："N 个币种无估值"、"已隐藏 N 个小额币种"（点击展开）。

**操作规则**
- 下拉刷新触发全量同步。
- 点击币种行 → P09；点击账户行 → P07 或 P08。
- 隐藏金额开启后，全 app 金额显示为 `****`，状态保留到手动关闭。
- 24 小时变化由当前估值与 24 小时前价格计算（数量按当前）；价格源不提供时显示"—"。

**页面状态**
- 空：没有任何账户。显示引导插图和"添加第一个账户"按钮。
- 加载：有缓存时先显示缓存并在顶部显示同步进度条；无缓存时显示骨架屏。
- 部分失败：正常显示，并出现同步失败提醒卡片。
- 全部失败且无缓存：显示错误说明和"重试"。
- 离线：显示缓存，顶部提示"当前离线，显示的是 xx 时间的数据"。

**元素**

**页面状态**：初始；验证中；验证失败（区分：凭据错误、网络错误、时间戳偏差、IP 限制）；权限警告。

### P13 设置主密码

**目的**：创建保险库。

**元素**
1. 说明文字：主密码的作用；**无法找回**的警告。
2. 主密码输入、再次输入；显示或隐藏切换；强度指示条。

### P14 导入密钥

**目的**：把助记词或私钥存入保险库。

**元素**
1. 类型分段：助记词｜私钥。
2. 条目名称（必填）。
3. **助记词**：
   - 词数选择：12、15、18、21、24。
   - 按词分格输入；输入时显示 BIP39 词表联想；支持整段粘贴后自动分词。
   - "高级"折叠区：BIP39 passphrase（可选）。
4. **私钥**：
   - 链类型选择：EVM、Bitcoin（WIF）、Solana、Tron。
   - 私钥输入框（默认遮挡）。
5. 关联账户（可选）：选择已有钱包账户，或"稍后在派生地址页处理"。
6. "保存到保险库"按钮。

**操作规则**
- 进入本页即启用防截屏与录屏检测（R26）。
- 助记词：每个词实时校验是否在词表内；全部填完后校验校验和，失败提示"助记词校验失败，请检查拼写和顺序"。
- 保存前须通过一次保险库验证（生物识别或主密码）。
- 重复检测：与已有条目内容相同时提示"该密钥已在保险库中：<条目名>"，不重复保存。
- 保存成功后清空所有输入，跳转 P16。
- 离开页面（返回、切后台）时清空已输入内容；返回时若有输入则先确认。

**页面状态**：输入中；校验错误；保存中；重复。

### P15 密钥详情

**目的**：查看单个密钥条目及其明文。

**元素**
1. 条目名称（可编辑）、类型、创建日期、关联账户。
2. 明文区：默认显示遮挡块和"验证后查看"按钮。
3. 验证后：助记词以带序号的网格显示；私钥以等宽字体分行显示；提供"以二维码显示"开关（默认关）。显示倒计时 60 秒。
4. BIP39 passphrase（若有）：单独一行，单独遮挡。
5. 已派生地址列表（只读摘要）与"管理派生地址" → P16。
6. 危险区："删除此密钥"。

**操作规则**
- 每次点击"验证后查看"都触发验证（R24）。
- 倒计时结束、离开页面、切后台时立即遮挡并清除内存中的明文。
- 删除规则见 R32。删除后关联账户的备份状态回到"未备份"（若未标记离线备份）。

**页面状态**：遮挡；已显示；验证失败；检测到录屏（隐藏内容并提示）。

### P16 派生地址

**目的**：从密钥条目算出各链地址，选择加入观察。

**元素**
1. 说明："以下地址由你的密钥计算得出，仅地址会被用于查询余额，密钥不会离开保险库。"
2. 链分段：EVM｜Bitcoin｜Solana｜Tron（私钥条目只有对应的一条链）。
3. 派生路径选择（每链有预设）：

| 链 | 预设路径 | 说明 |
|---|---|---|
| EVM | `m/44'/60'/0'/0/i` | 标准（MetaMask 等） |
| EVM | `m/44'/60'/i'/0/0` | Ledger Live |
| Bitcoin | `m/84'/0'/0'/0/i` | 原生隔离见证 bc1q（默认） |
| Bitcoin | `m/86'/0'/0'/0/i` | Taproot bc1p |
| Bitcoin | `m/49'/0'/0'/0/i` | 嵌套隔离见证 3 开头 |
| Bitcoin | `m/44'/0'/0'/0/i` | 传统 1 开头 |
| Solana | `m/44'/501'/i'/0'` | 标准（Phantom 等） |
| Solana | `m/44'/501'/i'` | 旧式 |
| Tron | `m/44'/195'/0'/0/i` | 标准 |

4. 地址列表：默认显示序号 0 到 4；每行显示序号、缩略地址、是否已在观察中、勾选框。"显示更多"每次加 5 个。
5. "检测余额"按钮：对当前列表中的地址查询是否有资产或历史活动，并标记。
6. 目标账户：新建钱包账户（默认以条目名命名）或加入已有账户。
7. "加入观察"按钮；"跳过"。

**操作规则**
- 进入本页需要一次保险库验证（派生需要解密）；派生完成后密钥立即清除，页面只保留地址。
- "检测余额"是联网操作，只发送地址。首次使用时说明这一点。
- 加入观察后，目标账户自动关联此密钥条目，备份状态变为"已入库"。
- 记录每个地址的派生路径，在地址面板中可见。

**页面状态**：派生中；正常；检测余额中；检测失败（不影响勾选）。

### P17 加密备份：导出与恢复

**目的**：把全部数据导出为一个可独立解密的文件，或从文件恢复。

**导出流程**
1. 说明页：备份包含什么（R39）；勾选"包含交易所 API Key"（默认不勾）。
2. 保险库验证（主密码，此处不接受生物识别）。
3. 设置备份密码：选择"使用主密码"或"另设密码"（输入两次）。
4. 生成文件（显示进度），文件名 `OneWallet-备份-YYYYMMDD-HHmm.owbak`。
5. 调起系统分享面板。
6. 结果页：提示存放建议；"我已保存到安全位置"按钮，点击后才更新"上次导出时间"。

**恢复流程**
1. 选择文件（系统文件选择器）。
2. 输入备份密码。
3. 预览：将恢复的账户数、地址数、密钥条目数。
4. 首次引导中恢复：直接写入，然后继续设置 PIN；若备份含保险库内容，须设置本机主密码（默认沿用备份密码，可改）。
5. 设置内导入：选择"合并"（跳过相同项，名称冲突时加后缀）或"取消"。v1.0 不提供"覆盖全部"。
6. 结果页：成功与跳过的数量。

**页面状态**：密码错误；文件损坏或版本不支持；进行中；完成。

### P18 设置首页

**元素（分组列表）**

- 其他：关于与帮助 → P22。

### P20 数据源设置

**目的**：配置链上数据和价格服务。

**元素**
- 各链数据服务：每条链一行，显示当前服务商和状态；点击可切换服务商、填写 API Key、测试连接。
- 自定义 RPC 地址（EVM、Solana，高级选项）。
- 价格源：服务商、API Key（可选）。
- 隐私说明："查询余额时，你的地址和 IP 会被发送给所选的数据服务商。"

**操作规则**：API Key 存入系统安全存储；未配置必需 Key 的链在添加地址时给出提示并引导到本页。

### P21 同步状态

**元素**
- 上次全量同步时间与耗时；"立即同步"按钮。
- 每个账户一行：状态（成功、失败、进行中）、上次成功时间、失败原因的可读说明。
- 最近 50 条同步日志（不含任何密钥和完整 API Key）。

### P22 关于与帮助

**元素**：版本号；安全设计说明（面向用户的简版）；备份文件格式与解密工具说明；常见问题（派生路径是什么、为什么地址对不上、API Key 怎么建）；开源许可列表。

## 9. 数据与内容

| 数据 | 来源 | 存放 |
|---|---|---|
| 账户、地址、标签、备份状态 | 用户输入 | 本地加密数据库 |
| 链上余额 | 各链数据服务（见 TECH_DESIGN 第 6 节） | 本地数据库（缓存） |
| 交易所余额、充值地址 | 交易所官方 API | 本地数据库（缓存） |

| 标准币种映射表 | 随 app 内置，可随版本更新 | 资源文件 |
| 净值快照 | 本地计算 | 本地数据库 |
| 助记词、私钥 | 用户输入 | 保险库（独立加密存储） |
| API Key、Secret、数据源 Key | 用户输入 | 系统安全存储 |
| 帮助内容、创建 API Key 的步骤 | 随 app 内置 | 资源文件 |

## 10. 异常与边界

| 情况 | 处理 |
|---|---|
| 无网络 | 显示缓存和离线提示；保险库功能完全可用 |
| 数据服务限频或宕机 | 该账户标记失败，保留旧数据；R17 重试 |
| 交易所 API Key 失效或被删 | P08 显示"Key 已失效"，引导更换 |
| 手机时间不准导致交易所签名失败 | 提示"设备时间偏差过大"，并以服务器时间校正后重试一次 |
| 代币无价格 | 估值显示"—"，不计入总额（R9） |
| 同一地址收到大量垃圾代币 | 默认过滤（R10） |
| 数量极大或极小 | 数量最多显示 8 位有效数字，极小值显示为 `<0.00000001` |
| 生物识别变更 | R30 |
| 用户忘记 PIN | 无法找回。提供"清除全部数据并重新开始"，之后可从加密备份恢复 |
| 用户忘记主密码 | 无法找回。若生物识别仍可用，可查看明文并手动抄录；提示尽快抄录并重建保险库 |
| 导入助记词时 app 被切到后台 | 清空输入（P14 规则） |
| 备份文件版本高于 app | 提示"请更新 app 后再恢复" |
| 存储空间不足 | 写入失败时提示，不破坏已有数据（写入须为原子操作） |
| 系统云备份、换机迁移 | 数据库和保险库均不参与系统备份；换机只能通过加密备份文件 |
| 越狱或 root 设备 | 启动时警告一次；保险库页面持续显示警示条；不阻止使用 |

## 11. 验收标准

**账户与同步**
- [ ] 添加一个 EVM 地址后 10 秒内看到六条链上的原生币和主流代币余额。
- [ ] 添加重复地址被拒绝，并提示所属账户。
- [ ] 四家交易所的总估值与官方 app 相差不超过 1%。
- [ ] 断网后打开 app，能看到上次数据和离线提示。
- [ ] 一个账户同步失败时，其他账户正常更新。

**应用锁**
- [ ] 回到前台超过设定时间后必须重新解锁。
- [ ] 任务切换器中看不到 app 内容。
- [ ] PIN 连错 5 次后被锁定并显示倒计时。

**保险库**
- [ ] 用 BIP39 官方测试向量导入，派生出的各链地址与预期完全一致。
- [ ] 用真实钱包的助记词导入，默认路径下派生的地址与原钱包显示一致。
- [ ] 校验和错误的助记词无法保存。
- [ ] 每次查看明文都要求验证；60 秒后自动遮挡。
- [ ] Android 上明文页无法截屏；iOS 上开始录屏后内容被隐藏。
- [ ] 新增一枚指纹后，查看明文要求输入主密码。
- [ ] 抓包确认：保险库的任何操作不产生网络请求；派生地址页的"检测余额"只发送地址。
- [ ] 日志和崩溃信息中搜索不到助记词片段、私钥、API Secret。

**备份清单**
- [ ] 新添加的观察钱包默认为"未备份"，并出现在总览提醒中。
- [ ] 入库并关联后，状态变为"已入库"，提醒数减一。

**加密备份**
- [ ] 导出的文件在另一台手机上用备份密码恢复，账户、地址、密钥条目数量一致，明文一致。
- [ ] 用仓库中的独立解密工具，在断网的电脑上能解出全部助记词。
- [ ] 错误的备份密码被拒绝，且不泄露任何内容。
- [ ] 卸载重装后，旧数据不会自动回来。
